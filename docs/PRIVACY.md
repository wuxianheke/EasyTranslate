# 隐私说明

最后更新：2026-07-29

## 概述

EasyTranslate 是一个直接在用户浏览器中运行的网页划词翻译扩展。扩展作者不运营中转服务器，也没有加入分析、广告或用户行为追踪功能。

使用翻译功能时，部分数据会直接发送到用户配置的 DeepSeek API。使用前请同时阅读 DeepSeek 的服务条款和隐私政策。

## 会发送给 DeepSeek 的数据

每次基础翻译请求可能包含：

- 用户主动选中的文字。
- 用于消歧的有限上下文。
- 配置的原语言和目标语言。
- 选择的模型及翻译提示说明。

“更多”请求还会包含基础译文，用于生成其他意思和双语例句。

短文本块可能作为完整上下文发送；较长内容只发送选区前后各 10 个词。页面 URL 不会作为翻译提示发送给 DeepSeek。

## API Key

- DeepSeek API Key 保存在 `chrome.storage.local`。
- API Key 不会通过 `chrome.storage.sync` 同步。
- API Key 只用于直接访问 `https://api.deepseek.com/`。
- 仓库不应包含真实 API Key；用户也不应在 Issue、日志或截图中公开它。

## 本地保存的数据

扩展可能在浏览器中保存：

- DeepSeek API Key：本地存储。
- 模型、原语言和目标语言：Chrome 同步存储；是否跨设备同步取决于用户的 Chrome Sync 设置。
- 全局模式开关：本地存储。
- 当前会话中已启用的标签页：会话存储。
- 基础翻译缓存：本地存储，有效期 2 天。

缓存键包含规范化页面地址、完整选词、上下文、语言方向、模型和提示词版本。缓存仅用于在同一页面复用基础译文。“更多”的返回内容不会缓存。

## 权限用途

- `activeTab`：在用户左键扩展图标后访问当前页面。
- `scripting`：向已开启的普通网页注入扩展脚本。
- `storage`：保存配置、状态和缓存。
- `contextMenus`：提供右键全局模式入口。
- `https://api.deepseek.com/*`：调用 DeepSeek API。
- 可选网页权限：仅在用户主动开启全局模式时申请；关闭全局模式后会主动撤回。

## 不会进行的行为

当前版本不会：

- 收集浏览历史用于分析或广告。
- 把 API Key 发送给扩展作者或非 DeepSeek 服务。
- 在未开启页面翻译时主动抓取页面内容。
- 缓存“更多”请求返回的扩展释义。
- 在扩展作者控制的服务器上建立用户档案。

## 删除数据

用户可以通过以下方式停止或删除相关数据：

- 关闭全局模式：停用全局翻译并撤回可选网页权限。
- 移除扩展：Chrome 会清理该扩展的本地数据；同步设置仍受用户的 Chrome Sync 状态和 Chrome 数据保留机制管理。
- 在 Chrome 的扩展管理界面撤回网站访问权限。

如果未来增加独立的缓存清理按钮、统计服务或新的 API 提供方，应同步更新本文档和扩展权限说明。
